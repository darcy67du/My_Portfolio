# Darcy Dushime — Portfolio

Premium, animated personal portfolio built with **Next.js 14**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**. Dark glassmorphism UI, live GitHub stats, and full SEO/OG support.

🔗 **Live site:** [my-portfolio-darcy5.vercel.app](https://my-portfolio-darcy5.vercel.app/)

## Tech Stack

React · Next.js · TypeScript · Tailwind CSS · Framer Motion · Lucide Icons

## Features

- Dark theme with glassmorphism cards
- Animated hero, particle background, mouse glow
- Skills, Projects, Experience, Education, GitHub Stats, Testimonials, Contact
- Fully responsive, accessible, SEO-optimized
